## Abstract

Conventional mortgage credit risk models rely exclusively on debt-to-income (DTI) ratios, systematically
omitting the shadow capital generated by domestic labour. This paper develops the Domestic Risk Mitigation
Index (DRMI), an AI-computable credit risk buffer measure that quantifies household shadow capital adequacy.
Using 3,295 PSID observations (2019 and 2021 waves), DRMI is constructed as the ratio of annualised
domestic service value to mortgage credit exposure (LGD = 0.20). Homemaker households hold 2.06 times
more DRMI than dual-income households (t = 6.18, p < 0.001), representing a $40,227 annual domestic
service gap. Single-income applicants face a 2.62 percentage point mortgage denial premium despite
identical origination-stage DTI ratios (HMDA 2023, chi-sq = 34.6, p < 0.001). DRMI improves default
model fit substantially (AIC: 541 to 419).

## PSID Data Notice

The Panel Study of Income Dynamics (PSID) is publicly available but requires free registration
at [psidonline.isr.umich.edu](https://psidonline.isr.umich.edu). The derived analytical datasets
in the `data/` folder were constructed by the author from PSID Public Use files. These files
contain no raw PSID response variables and have been transformed through DSV computation,
DRMI indexing, and winsorization. Raw PSID data files cannot be redistributed per the PSID
Data Use Agreement (University of Michigan, Institute for Social Research).

## How to Reproduce the Analysis

### Requirements
- Python 3.12+ (Anaconda recommended)
- See `requirements.txt` for full package list

### Setup
```bash
git clone https://github.com/[YOUR_GITHUB_USERNAME]/DRMI-Mortgage-Risk-Index
cd DRMI-Mortgage-Risk-Index
pip install -r requirements.txt
```

### Run
1. Start Jupyter: `jupyter notebook`
2. Open and run `notebooks/DRMI_data_analysis_FINAL.ipynb` (Cells 0-8 in order)
3. Open and run `notebooks/DRMI_regression_analysis_FINAL.ipynb` (Cells 0-19 in order)

### File Paths
The notebooks use relative paths from the project root. Set `BASE = os.getcwd()` in Cell 0.
All processed data files must be in `data/` subfolder structured as `08_Processed/analytical/`
and `08_Processed/merged/` to match the notebook path conventions.

## DRMI Formula

```
DRMI = DSV_annual / (Mortgage_Balance x LGD)

DSV_annual = [H_housework x $17.39 + H_childcare x $15.93 + H_eldercare x $22.64] x 52

Where:
  H_i = weekly hours in category i (PSID time-use supplement)
  Wages = BLS OEWS May 2024 (SOC 37-2012, 39-9011, 21-1093)
  LGD   = 0.20 (Basel Committee residential mortgage floor)
```
